SECTION 4 — CREDENTIAL FORMATS BEING DETECTED
GCP Service Account Key
The GCP credential is a JSON file. Detection anchors on the client_email field and confirms via the type field.
What
Field
Pattern
Primary anchor
client_email
[a-z0-9\-.]+@[a-z0-9\-]+\.iam\.gserviceaccount\.com
Confirmation
type field
"type":\s*"service_account" in same file/diff chunk
Key ID anchor
private_key_id
"private_key_id":\s*"([a-f0-9]{40})"
Azure Service Principal / Client Secret
What
Format
Detection Rule
Client ID (App ID)
UUID format
[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12} near clientId /
AZURE_CLIENT_ID keywords
Client Secret
40+ char alphanumeric
Near clientSecret / client_secret / AZURE_CLIENT_SECRET
keywords
Connection String
Self-contained
DefaultEndpointsProtocol=https;AccountName=...;AccountKey=[64+
chars];
