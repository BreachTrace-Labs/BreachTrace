# GCP incident timeline development cases v1

Frozen before execution. Six source patterns are repeated with synthetic key roles swapped: target, sibling, missing key field, malformed key field, unrelated principal and missing association. Twelve constructed incidents are paired by pattern, with swapped roles kept within the same cluster. Missing/malformed cases have generator truth target in one world and sibling in the other, but identical observable evidence. Missing association cases have target/sibling generator truth. Unrelated principal cases are non-target and baseline abstains. All timestamps and operations are equal and in-window. Actual incident detail route is invoked against persisted rows, not the full collection pipeline.

Arms: BT translates matched/ different_key/ unavailable-or-null to target/other/unknown; B0 always unknown; B1 assigns within-window same-principal records to target and abstains otherwise; B2 checks same principal, valid key resource, and association, returning target/other/unknown using the same visible fields. Compare decisions against fixture generator truth and separately require an explicit key and matching principal for an evidence-warranted target. No credentials, live providers, external network or model writers. Report denominators, abstentions and unavailable separately. Development examples are not 12 independent sources, no significance test or population inference. No independent baseline author or blinded reviewer is available; review pending.
