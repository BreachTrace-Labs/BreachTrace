# Field retention development fixture v1

Registered before execution. Four constructed records: GCP target key present, GCP key missing, AWS CloudTrail lookup and AWS trail-file adapter with a signing key. Each record is an independent fixture case; there is no native action ledger or acquisition manifest. Record presence of source record ID, principal, exact-key field, operation, timestamp and success before mapping, after the actual mapper and after actual SQLite persistence. AWS key presence is measured inside the nested original CloudTrail JSON; this does not prove a downstream attribution. GCP presence is read from authenticationInfo.serviceAccountKeyName. Absent source fields are inapplicable to retention, not losses. For each stage, counts use source-present fields as denominator. Separate AWS lookup and trail modes. Source and field values are inert. This experiment does not measure native action visibility, acquisition, or accuracy; reviewer adjudication is pending.
